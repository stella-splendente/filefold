# 브랜드명: Filefold

결정일: 2026-09-21

## 선택
- 브랜드: **Filefold**
- 도메인: `filefold.app` (2026-09-21 RDAP 조회 결과 미등록. `.com`은 등록됨)
- 스위트 표시명: `Filefold PDF Tools`, `Filefold Image Tools`, `Filefold Audio Tools`
- Firefox gecko id: `pdf@filefold.app`, `image@filefold.app`, `audio@filefold.app`
- 코드 패키지 스코프는 `@filekit/*` 유지(작업명), 브랜드는 표시명·도메인에만 사용

## 근거
- RDAP(verisign .com, Google registry .app) 조회: 대조군 무작위 이름이 404로 나와 조회 유효
- `.app` 가용 후보: privfile, filefold, localfilekit, offlinefile, filepriv, filelocal
- WebSearch `"privfile" OR "filefold" chrome extension`: 동명 확장 없음
- filefold는 "파일을 접어 정리한다"는 중립적 어감으로 PDF·이미지·오디오 어느 스위트에도 맞고, privfile은 privacy 연상은 좋으나 발음이 어색

## 탈락
- keepfile, filenook, quietfile, tidyfile, fileloom, keeplocal, localdrop, privkit: `.com`·`.app` 모두 등록됨
- dropquiet: 둘 다 가용하나 파일 도구와 연결이 약함

## 미확인
- 정식 상표 조회는 하지 않음(무료 간이 검색만). 매출이 생기면 KIPRIS·USPTO 조회 권장
- 도메인 구매는 스펙 §2.2에 따라 사이트 유입이 생긴 뒤 선택
