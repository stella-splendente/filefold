# filekit v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 브라우저 안에서만 동작하는 파일 도구 세트(PDF·이미지·오디오)를 확장 프로그램 3종 + 정적 도구 사이트로 만들고, 스토어 게시·사이트 배포·검증을 GitHub Actions로 무인화한다.

**Architecture:** 처리 엔진(`packages/core`)은 DOM을 모르는 순수 브라우저 코드이며 Web Worker에서 실행된다. 확장(WXT, MV3)과 사이트(Astro)는 같은 `packages/ui`·`packages/license`를 조립한 얇은 껍데기다. 유료 기능은 Polar 라이선스 키를 클라이언트가 직접 검증하며 서버는 없다.

**Tech Stack:** pnpm 12 workspace, TypeScript 5, Preact 10, WXT 0.21, Astro 7, pdf-lib 1.17, pdfjs-dist 6, @jsquash/* (wasm 코덱), heic-to, @ffmpeg/ffmpeg 0.12 (single-thread core), comlink, fflate, Vitest 5, @playwright/test 1.63, GitHub Actions + PlasmoHQ/bpp v3 (스토어 게시), wrangler (Cloudflare Pages).

**Spec:** `docs/superpowers/specs/2026-09-21-filekit-design.md`

## Global Constraints

- 고정비 0. 새 유료 서비스·유료 패키지 금지. Chrome 등록 $5는 사용자가 결제.
- 서버 0. 네트워크 호출은 Polar 공개 API(`https://api.polar.sh/v1/customer-portal/license-keys/{activate,validate}`)뿐.
- 파일은 기기 밖으로 나가지 않는다. 어떤 코드도 파일 내용을 전송하지 않는다.
- 확장은 Manifest V3, 원격 코드 없음, wasm 동봉, CSP `script-src 'self' 'wasm-unsafe-eval'`.
- 무료 한도: 한 번에 파일 1개, 파일당 25MB(26,214,400 bytes), 하루 10회. Pro: 파일 수 무제한, 파일당 2GB, 횟수 무제한.
- 가격: 스위트당 $9.99 평생, 3종 묶음 $19.99 평생. 활성화 한도 기기 3대. 재검증 7일, 유예 30일.
- 언어: 영어 기본 + 한국어. 문구는 `packages/ui/src/i18n/{en,ko}.json` 단일 관리.
- 파일 500줄 이하. 함수 50줄 이하. `core` 라인 커버리지 80% 이상.
- 커밋 메시지 `<type>: <description>` (feat, fix, test, chore, docs, ci).
- 진행 상황은 `docs/PROGRESS.md`에 작업 단위로 기록한다(세션이 끊겨도 재개 가능하도록).

```ts
export type Suite = "pdf" | "image" | "audio";
export interface KVStore { get(k: string): Promise<string|null>; set(k: string, v: string): Promise<void>; remove(k: string): Promise<void> }
export interface LicenseState { tier: "free"|"pro"; suites: Suite[]; key?: string; activationId?: string; lastValidatedAt?: number; graceUntil?: number }
export class LicenseClient {
  constructor(opts: { organizationId: string; store: KVStore; fetch?: typeof fetch; now?: () => number; revalidateMs?: number; graceMs?: number })
  activate(key: string, label: string): Promise<LicenseState>   // POST .../activate {key, organization_id, label}
  getState(): Promise<LicenseState>                              // 캐시 → 7일 지나면 validate → 실패 시 유예 판단
  deactivate(): Promise<void>
}
export const FREE_LIMITS = { maxFiles: 1, maxFileBytes: 26_214_400, dailyOps: 10 } as const;
export const PRO_LIMITS  = { maxFiles: Infinity, maxFileBytes: 2_147_483_648, dailyOps: Infinity } as const;
export class Quota {
  constructor(store: KVStore, now?: () => number)
  check(tier: "free"|"pro", files: { size: number }[]): Promise<{ ok: true } | { ok: false; reason: "TOO_MANY_FILES"|"FILE_TOO_LARGE"|"DAILY_LIMIT" }>
  record(): Promise<void>   // 일자별 카운터 증가 (키 `quota:YYYY-MM-DD`)
}
```

- Polar 응답 매핑: `activate` 200 → `{tier:'pro', suites: benefitToSuites(res.license_key.benefit_id), activationId: res.id}`. `benefit_id → Suite[]` 매핑 테이블은 `polar.ts`의 `BENEFITS` 상수(빌드 시 환경변수 `VITE_POLAR_BENEFITS` JSON 주입, 형식 `{ "<benefit_id>": ["pdf"] , "<bundle_benefit_id>": ["pdf","image","audio"] }`). 403/404 → `INVALID_KEY`, 그 외/네트워크 → `NETWORK`.

- [ ] **Step 1: 실패 테스트** — (a) activate 성공 시 pro 저장, (b) 유효한 캐시 7일 이내면 fetch 호출 0회, (c) 8일째 validate 200이면 갱신, (d) validate 네트워크 실패면 pro 유지 + graceUntil = lastValidatedAt+30일, (e) 유예 만료 + 실패 → free, (f) validate 403 → 즉시 free. Quota: 파일 2개 free → TOO_MANY_FILES, 25MB+1 → FILE_TOO_LARGE, 10회 후 → DAILY_LIMIT, 날짜 바뀌면 리셋, pro는 모두 ok.
- [ ] **Step 2: 실패 확인** → **Step 3: 구현** (`fetch` 주입, `now` 주입, 저장 키 `license:state`) → **Step 4: 통과**
- [ ] **Step 5: Commit** — `feat(license): polar license client with grace period and free quota`
